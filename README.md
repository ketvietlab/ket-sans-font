# KÉT Sans

Phông chữ thương hiệu của Két Việt: neo-grotesque trung tính cho giao diện tiếng Việt.
- Năm độ đậm: Light 300, Regular 400, Medium 500, Bold 700 và Black 900.
- Một bản Variable (wght 300–900, opsz 8–72).
- 530 ký tự, gồm Latin, tiếng Việt và ₫.

**Tải về:** mục [Releases](https://github.com/ketvietlab/ket-sans-font/releases/latest), tệp `KETSans-<phiên bản>.zip`. Kiểm tệp bằng `shasum -a 256 -c SHA256SUMS`.

Gói có:

| Thư mục | Dùng cho |
| --- | --- |
| `OTF/` | Cài vào máy (macOS, Windows, Linux), thiết kế và in ấn |
| `TTF/` | TrueType có hint, cho Windows và phần mềm chỉ nhận TTF |
| `WOFF2/` | Font tĩnh có hint cho website |
| `Optical/` | TTF và WOFF2 có trục `opsz`, mỗi độ đậm một file |
| `Variable/` | Một file chứa mọi độ đậm 300–900 và trục `opsz`; gọn nhất cho website |

Hướng dẫn `@font-face` nằm trong `README.txt` của gói.
